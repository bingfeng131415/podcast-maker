# 政策、法规和官方文件

适用：法律法规、部门规章、通知、意见、办法、行业标准、征求意见稿、地方政策、公司或机构的正式规定。

## 听完要带走

1. 谁发的、叫什么、哪天发、哪天生效、全国还是某地。
2. 一句话：这份文件干了什么。
3. 主要改了什么：和以前比，哪里新增、哪里放宽、哪里收紧。
4. 影响谁、怎么影响：几类典型的人或企业，分别会遇到什么。
5. 要做什么：有没有截止时间、要不要办手续、去哪办。
6. 还没说清的：要等细则的、有歧义的地方。

## 精讲稿里要标【】的

- 发文机关、文件简称、发布日期、生效日期。
- 每一条关键数字：金额、比例、年限、年龄、人数、门槛、上限，照原文写。
- 新旧对比里变化最大的一两处（"从 X 改成 Y"）。
- 适用范围和主要例外。
- 时间节点：过渡期、截止日。
- 处罚、补贴、奖励的具体标准。
- 文件状态：正式稿还是征求意见稿、试行。

## 怎么讲给外行

- **翻成"如果你是……"**：挑 2～3 个典型的人（"一个在外地工作的年轻人""一家十几个人的小公司"），说清是举例，然后讲他会遇到什么。
- **官方说法先说一次原话，再翻成大白话**："文件里叫'灵活就业人员'，就是没有固定单位的，比如跑外卖、开网约车的。"之后固定用大白话。
- **关键条款引一次原话**（"文件原话是……"），再说意思。不整段念条文。
- **数字算给人听**："上限从五千提到八千，一个月最多能多……"。自己算的要说"我算了一下，按……来算"。
- **分清文件层级**：法律、条例、办法、通知、意见、征求意见稿约束力不一样。征求意见稿一定要说"还没定，可能会改"。

## 对谈怎么展开

- 开场：来源交代一次（机关、文件名、日期），一句话说它干了什么，为什么值得听（影响面多大）。
- 正文按"改动点"或按"人群"分段，二选一，别混。每段末尾小结"所以对……来说，就是……"。
- 主持人代表普通人问："那我要做什么？""我家这种情况算不算？""什么时候开始？"
- 讨论段聊：为什么现在出（文件里写的背景或公开报道，推测要说是推测）、执行时可能卡在哪、还有哪些要等细则。讨论效果和执行，不替听众站政治立场。
- 自测问"某类人会受什么影响""哪天开始生效""改的最大的一处是什么"。

## 容易出错

- 征求意见稿当成正式稿；地方政策说成全国；发布日期说成生效日期。
- 数字记错或说成大概——政策的数字要准，可以说准了再补一句"也就是差不多……"。
- 不给法律、税务、投资建议。个人情况复杂的说"具体去问……（社保局、律师、税务）"。
- 不用"重磅""史上最严""炸了"这类词。
- 原文没写的细节不补，说"文件里没写，要等细则"。

## 示例片段（自己写的）

```
女：我直接问啊，这个文件跟我这种自由职业的有关系吗？
男：有，而且关系不小。文件里有个词叫"灵活就业人员"，说的就是没有固定单位的人。
女：跑外卖的、接私活的，都算？
男：都算。原来这类人交社保，只能在户口所在地交……
女[抢]：对，我就卡在这儿过。
男：这次改的就是这条：可以在工作的地方交了。
```
