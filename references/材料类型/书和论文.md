# 书和论文

适用：人文社科和思维类的书（心理学、哲学、批判性思维、管理、社会学……）、学术论文、研究报告、白皮书。

## 听完要带走

1. 核心论点：一句话。
2. 作者怎么得出来的：论证的两三步。
3. 关键概念：2～4 个，每个能用自己的话说出来。
4. 最有说服力的例子或证据。
5. 哪里说得对，哪里可能说过头了。

论文和研究报告还要讲清：
- 研究的问题是什么。
- 怎么研究的（大白话：调查了多少人、做了什么实验、对比了什么）。
- 主要发现（数字）。
- 局限：样本、地区、时间、能不能推广。

## 精讲稿里要标【】的

- 核心论点里的关键词。
- 每个关键概念的名字（用对谈里会说的叫法）。
- 作者的代表性例子（一两个词就够定位，如【停车场的例子】）。
- 论文：样本量、主要结果的数字、研究对象。
- 作者明确写出的结论或建议。

## 怎么讲给外行

- **概念按"作者造这个词是为了说明什么"来讲**，不背定义。
- **一个概念两个例子**：作者的例子 + 听众生活里的例子（说明是自己举的）。
- **统计结果翻成大白话**："显著"不等于"很大"，是"不太可能是碰巧"；"提高了 20%"要说从多少到多少；能用"每 100 个人里……"就用。
- **相关和因果分开**："两件事一起出现，不代表一个导致另一个。"
- **哲学和理论书**：先讲作者在反对什么，再讲他主张什么，比直接讲主张好懂。

## 对谈怎么展开

- 开场：交代书名、作者、哪一章（论文：哪个机构、什么期刊、哪年），一两句说它的核心论点，为什么值得听。
- 正文每段从一个问题或一个常见误解切入，再讲作者的回答。
- 主持人可以替常识反驳："可我平时就是这么做的，也没出问题啊？"
- 讨论段聊：作者说得对的地方、说过头的地方、在听众自己的生活或工作里怎么用。
- 自测问概念的运用："如果有人这么说……，按这一章的说法，问题出在哪？"

## 容易出错

- 书里引用的别人的观点，别说成作者的观点。
- 单个研究不说成定论，说"这项研究发现"。
- 动物实验、小样本、某一个国家的数据，不直接推到所有人。
- 一章书不要每节都讲，挑最核心的两三个点讲透。

## 示例片段（自己写的）

```
女：这一章那个词，叫……"自我审视"？我第一反应是，这不就是反省吗？
男：很接近，但作者想说的更具体一点。不是"我错了没有"，是"我为什么会这么想"。
女：这俩有什么区别？
男：举个我自己编的例子。你看到一个新闻，第一反应是"肯定是假的"。反省是问"我判断对了吗"……
女[抢]：自我审视是问，我为什么一看就觉得是假的。
男：对，是不是因为发这条新闻的人，我本来就不喜欢。
```
