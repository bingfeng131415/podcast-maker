# 时政和国际

适用：政治新闻、选举、外交、国际关系、地区冲突、贸易摩擦、重要会议和讲话的报道与分析。

## 听完要带走

1. 发生了什么：时间、地点、谁、做了什么（只讲事实）。
2. 为什么会这样：两三个背景节点。
3. 各方怎么说：每一方的立场和他们自己给的理由。
4. 接下来可能怎样：文章或分析人士提到的几种可能。
5. 跟普通人有什么关系：价格、出行、工作、投资环境……只讲材料里有依据的。

## 精讲稿里要标【】的

- 事件的时间、地点。
- 关键人物和机构（带身份）。
- 关键数字：票数、比例、金额、关税税率、人数，带出处。
- 各方的核心表态（原话的要点）。
- 背景时间线上最关键的一两个节点。

## 怎么讲给外行

- **人物第一次出现先说身份**："美国国务卿，相当于外交部长。"之后可以只说身份或只说名字，固定一种。
- **制度用对照讲**："参议院，你可以先理解成……"，对照不准的地方说一句。
- **时间线最多三个节点**："三年前……去年……这一次……"
- **多方关系先讲两方**，第三方等前两方讲清楚再加。
- **地名、组织名用通行的中文叫法**，缩写第一次说全称。

## 对谈怎么展开

- 讲解者先讲事实，主持人再问"那各方怎么看"。事实和观点分两步走。
- 各方的说法都用"某方的说法是……"，不替任何一方下结论。
- 讨论段可以聊：各方理由的逻辑通不通、还缺什么信息、几种走向各需要什么条件。涉及党派、意识形态、领土这类争议时，呈现主要几方的理由，主持人和讲解者不站队、不给听众结论。
- 材料本身是评论文章时，作者的立场说成"作者认为"，可以讨论它的理由，同时补一句另一方通常怎么回应。
- 自测问事实和因果："这次的导火索是什么？""某方最在意的是哪一点？"

## 容易出错

- 只有一方的消息来源时说明"目前只有……的说法"。
- 没证实的消息说"据报道""还没有确认"。
- 时效：说"截至文章发出的时候"。
- 不用贬损性的称呼和标签，用对方的正式名称。
- 涉及冲突、伤亡、灾难：语气平实，不开玩笑，不加笑声和 `happy` 情绪，不写抢话打断。
- 不预测选举结果、战争胜负，只转述材料里的分析。

## 示例片段（自己写的）

```
女：我先确认一下事实啊，这次到底是谁宣布的？
男：是对方的商务部，上周五宣布的，从下个月一号开始，对这几类商品加征百分之二十五的关税。
女：百分之二十五，听起来挺狠的。他们自己怎么解释？
男：他们的说法是，要保护本国的制造业。
女：那被加税的这一方呢？
男：这边的回应是，这违反了之前达成的协议，会采取对等措施。两边说的，咱们先都放在这儿。
```
