# 商业和财经

适用：公司财报、行业分析、公司战略和人物、宏观经济数据（GDP、CPI、利率）、市场行情评论、创业和商业模式文章。

## 听完要带走

1. 发生了什么：用两三个数字说清。
2. 为什么：背后的主要原因。
3. 意味着什么：对这家公司、这个行业、普通人。
4. 不确定在哪：哪些是预测，哪些还看不清。

## 精讲稿里要标【】的

- 关键数字：营收、利润、增速、市场份额、价格、利率、涨跌幅，带时间口径（哪个季度、哪一年）和比较方式（跟去年同期比，还是跟上个季度比）。
- 公司和人物（带身份）。
- 作者或分析师的核心判断，以及给的理由。
- 最关键的一个原因。

## 怎么讲给外行

- **财务词翻成生活的话**："毛利率，就是卖一百块钱的东西，扣掉进货成本还剩多少。"
- **同比、环比不说这两个词**，说"跟去年同一时候比""跟上个季度比"。
- **大数换个尺度**："一千二百亿，差不多是……"；一期里尽量用同一种单位（都说人民币，或都说美元）。
- **百分比和百分点分开**：利率从 3% 到 4%，是"涨了一个百分点"，不是"涨了 1%"。
- **一个时间点讲一组数**，不在一句里塞三个时间。

## 对谈怎么展开

- 开场：一个最抓人的数字或反常现象（"卖得更多了，赚得反而少了"）。
- 正文按"数字 → 原因 → 影响"走。
- 主持人替普通人问："这跟我有什么关系？""东西会涨价吗？""这家公司是不是要不行了？"
- 讨论段聊：作者的判断有没有道理、还有什么别的解释、哪些信号值得接着看。
- 自测问因果："利润下降，主要是哪个原因？"

## 容易出错

- 不给投资建议：不说"值得买""该卖了""会涨"。听众问到就说"这个我们给不了建议"。
- 预测说成预测，说清是谁的预测。
- 口径别混：亿元和亿美元、税前和税后、年化和单月。
- 公司自己发的数字和第三方估算分开说。

## 示例片段（自己写的）

```
女：我看到这个数的时候愣了一下。卖得比去年多，赚得反而少了？
男：对，营收涨了一成多，利润掉了差不多三成。
女：钱去哪了？
男：大头是价格战。为了抢市场，每台车都在降价，你可以理解成，卖一辆车，比去年少赚好几千块。
女：那它为什么还要降？
男：这就是作者想聊的。他的判断是，现在不降，明年连卖的机会都没有。
```
