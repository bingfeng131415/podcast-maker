# 新闻、评论和观点文章

适用：社会新闻、深度报道、评论文章、观点长文、人物访谈、行业观察。

## 听完要带走

1. 作者（或受访者）的主张：一句话。
2. 他的理由：两三条。
3. 他用的事实和数字。
4. 最常见的反对意见是什么。
5. 我们怎么看：理由站不站得住，还缺什么信息。

## 精讲稿里要标【】的

- 作者是谁、什么身份或立场（如果文章里有）。
- 核心主张的关键词。
- 每条理由的关键词。
- 关键事实和数字。
- 文章里最有代表性的一个例子或一句话。

## 怎么讲给外行

- **先把作者的观点讲到最有说服力的样子**，再讨论。不先挑毛病。
- **事实、作者的观点、我们的看法分三层说**："这件事是……""作者认为……""我觉得……"
- **长文的论证理成一条线**："他先说……，所以……，最后得出……"

## 对谈怎么展开

- 开场：作者是谁、发在哪、一句话说他的主张，再说为什么这个话题现在值得聊。
- 正文：每条理由一段，主持人复述后提最常见的反对意见。
- 讨论段：两人可以意见不同，结尾各自说服对方一点。
- 自测问论证："作者最关键的一条理由是什么？如果这条不成立，结论还站得住吗？"

## 容易出错

- 把作者的观点说成事实。
- 只讲文章的一方，不提另一方通常怎么说。
- 社会新闻里的当事人是普通人时，不评价他的人品，不猜测没报道的细节。

## 示例片段（自己写的）

```
女：这篇的标题挺冲的，说"年轻人不该再考公了"。
男：标题是冲，但他的理由其实挺具体的，我先替他讲一遍。
女：好，你先当他的辩护律师。
男：第一条，他算了一笔账：考三年，放弃的工资和经验……
女：可这只是算钱。很多人考公，图的是稳定啊。
男：这正好是他第二条要说的。
```
