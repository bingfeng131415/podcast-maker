# 科学、医学和健康

适用：科普文章、科研新发现、医学和健康研究、营养、运动、心理健康、环境和气候。

## 听完要带走

1. 发现了什么（一句话）。
2. 怎么发现的，证据有多硬（在人身上还是动物身上、多少人、多长时间）。
3. 对我意味着什么：能不能改变日常做法，还是只是"值得关注"。
4. 还不知道什么。

## 精讲稿里要标【】的

- 研究对象和规模：多少人、什么样的人，或者是动物、细胞。
- 主要结果的数字，最好有绝对数（"每一千人里从 10 个降到 7 个"）。
- 做研究的机构、发表的期刊和时间。
- 作者或专家给出的建议原话。
- 药物名、剂量、指标名照原文写。

## 怎么讲给外行

- **机制用类比**：免疫系统像小区保安、血管像水管、神经递质像传纸条。说一个就够。
- **风险用"每多少人里有几个"**：相对风险"降低 30%"要配上绝对数，否则听着比实际吓人或诱人。
- **证据分档说**：一项小研究、多项研究的汇总、官方指南，分量不一样，要说是哪一种。
- **"相关"和"因果"分开**："喝咖啡的人更长寿，不代表咖啡让人长寿，可能是……"

## 对谈怎么展开

- 开场：一个日常问题（"每天喝几杯咖啡算多？"），再说今天这项研究给了什么新答案。
- 正文按"发现 → 证据 → 怎么理解"走。
- 主持人替普通人问："那我该不该改？""我家老人适用吗？""会不会过两年又说反了？"
- 讨论段聊：证据的强弱、和以前的说法冲不冲突、媒体报道有没有夸大。
- 自测问理解："这项研究为什么还不能说明……？"

## 容易出错

- 不给个人医疗建议。涉及用药、治疗、停药、具体病情，说"具体问医生"。
- 动物实验、细胞实验不推到人身上。
- 不说"治愈""神药""一定"。
- 疾病、死亡、心理危机这类严肃话题：语气平实，不开玩笑，不加笑声。

## 示例片段（自己写的）

```
女：所以结论是，每天走七千步就够了，不用一万步？
男：这项研究是这么说的，但得先说它怎么得出来的。
女：嗯，你说。
男：研究者汇总了十几项研究，加起来十几万人，看走路多少和寿命的关系。
女：那七千步和一万步，差别大吗？
男：差得不多。他们发现过了七千步左右，再往上走，好处就涨得很慢了。不过这是相关，不是说你今天开始走七千步就一定能多活几年。
```
