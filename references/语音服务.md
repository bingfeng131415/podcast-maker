# 声音和语音服务

## 配置分层（后面的覆盖前面的）

1. `<SKILL_DIR>/voices.json`：公开默认配置（服务商、各家设置、默认音色、公开预设）。
2. `<USER_DIR>/config.json`：个人配置（默认 `~/.config/podcast-maker/config.json`）。放密钥文件位置 `env_file`、个人的默认音色、克隆声音预设、发送命令 `send`。格式见 `<SKILL_DIR>/config.example.json`。
3. 这一期文件夹里的 `voices.json`：只对这一期生效。
4. 命令行 `--voice <预设名>`：从以上各层的 `presets` 里取。

## 配置示例

```json
{
  "provider": "minimax",
  "providers": { "minimax": { "model": "speech-2.8-hd" } },
  "speakers": {
    "女": { "role": "主持人", "voice_id": "Chinese (Mandarin)_Warm_Bestie" },
    "男": { "role": "讲解者", "voice_id": "Chinese (Mandarin)_Reliable_Executive", "speed": 1.0, "pitch": 0, "vol": 1.0 }
  },
  "presets": {
    "电台": { "男": { "voice_id": "Chinese (Mandarin)_Radio_Host" } },
    "豆包": { "provider": "doubao", "女": { "voice_id": "<豆包音色ID>" }, "男": { "voice_id": "<豆包音色ID>" } }
  }
}
```

- `speakers` 的键就是对谈稿里的说话人标签。
- 每个说话人可以单独写 `provider`，两个人用不同的服务商；脚本会先把两个声音的音量对齐再拼接。
- 预设里除 `provider` 以外的键都是说话人，只写要改的字段就行。

## 服务商

| `provider` | 需要的密钥 | 说明 |
|---|---|---|
| `minimax`（默认） | `MINIMAX_API_KEY`；海外站另设 `MINIMAX_API_HOST=https://api.minimax.io` | 实测可用。支持声音标记、情绪、发音词典、克隆音色 |
| `doubao`（豆包 / 火山引擎） | `DOUBAO_APPID`、`DOUBAO_ACCESS_TOKEN` | 按公开文档写的，没有实测。`voice_id` 填控制台里的音色 ID |
| `elevenlabs` | `ELEVENLABS_API_KEY` | 按公开文档写的，没有实测。中文用多语言模型 |

- 密钥写在环境变量里，或写进 `<USER_DIR>/.env`（格式见 `<SKILL_DIR>/.env.example`）。不要把密钥读出来，也不要写进其他文件或回复。
- 声音标记和句内停顿只有 MiniMax 认识；用别家时脚本自动去掉，不会念出来。
- 第一次用某家服务商或某个新音色，先用 `examples/样片/` 或一小段稿子跑样片，确认能用、好听，再做整期。
- 加新的服务商：在 `scripts/tts-providers.mjs` 里照着现有的写一个函数，放进 `PROVIDERS`，在 `KEYS` 和 `DEFAULTS` 里补上。

## 发送到手机

`<USER_DIR>/config.json` 里的 `send` 是一条命令（数组，每段一项），`{file}` 会换成 MP3 文件名，`{title}` 换成标题，在这一期的文件夹里执行。例如用飞书命令行工具发给自己：

```json
{ "send": ["lark-cli", "im", "+messages-send", "--as", "bot", "--user-id", "<你的 open_id>", "--file", "{file}"] }
```
